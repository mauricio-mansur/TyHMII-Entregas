# Módulo 3: Taller de Fotografía

## Descripción del Proyecto
Este repositorio contiene el informe técnico correspondiente al Módulo 3. 

El objetivo de este trabajo práctico es aplicar técnicas de fotografía forense para el registro, análisis e interpretación de evidencias visuales en el ámbito de la ingeniería. A través de un taller práctico, exploramos cómo la correcta captura de imágenes y el análisis de sus parámetros técnicos pueden servir como prueba documental y base para la toma de decisiones técnicas.

## Contenido del Informe
El análisis desarrollado en este documento se divide en dos áreas principales de aplicación:

1. **Análisis de Falla de Material:** Estudio pericial de la rotura de una barra de acero corrugado. Incluye la interpretación del mecanismo de rotura (transición dúctil-frágil, fatiga y corrosión) y la extracción de metadatos (EXIF) para garantizar la trazabilidad legal y técnica de la evidencia fotográfica.
2. **Análisis Técnico de Parámetros Fotográficos:** Evaluación crítica de una captura documental de un evento, aplicando los conceptos del taller para desglosar elementos como la iluminación, composición, profundidad de campo, saturación y el contexto del entorno.
