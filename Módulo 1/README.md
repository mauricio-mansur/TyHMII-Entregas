# Módulo 1: Toma de Decisiones

# Selección y Evaluación de Factibilidad del Trabajo Final de Carrera mediante Gemini Notebook

## Descripción del Proyecto
Este repositorio contiene el Trabajo Práctico Nº1 correspondiente al Módulo 1: Toma de decisiones de la materia Técnicas y herramientas modernas II (Carrera de Ingeniería Industrial, Universidad Nacional de Cuyo, 2026).
El objetivo principal del trabajo consistió en utilizar Gemini Notebook como un entorno de investigación interactivo para analizar, sintetizar y comparar dos propuestas temáticas preseleccionadas para el proyecto final académico. Esto permitió tomar una decisión fundamentada en datos, evidencia científica y alineación vocacional.

## Temas Evaluados
Durante el proceso de investigación se contrastaron dos líneas de trabajo:
* **TEMA A**: Plataformas Inteligentes de Gestión y Confiabilidad Operacional para la Cadena de Valor Metalmecánica.
* **TEMA B**: Planificación y Optimización de infraestructura vial de rutas nacionales referido a la industria de los hidrocarburos.

## Decisión Final: Tema A
Tras evaluar la disponibilidad de información, la viabilidad técnica, el aporte de ingeniería y la factibilidad temporal, el equipo seleccionó el **Tema A** como opción definitiva para el Trabajo Final de Carrera.
